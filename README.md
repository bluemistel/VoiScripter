# VoiScripter - ブラウザで動作する合成音声ソフトの台本作成支援アプリ

## 概要
VoiScripterは、合成音声ソフト系の台本作成に向いたブロックベースのテキストエディタです。*1<br>
Webアプリケーションとしても、デスクトップアプリケーションとしても動作します。<br>
*1 合成音声系台本に向いているというのは個人の主観です<br>

## 使い方・配布先
Web版
https://voiscripter.vercel.app/ にアクセス

デスクトップ版(Booth)<br>
https://bluemist.booth.pm/items/7272767

## 主な機能
- ブロックベースの台本作成・編集（ドラッグ並び替え、複数選択の一括操作、クロスシーン移動、アンドゥ/リドゥ、検索）
- キャラクター管理（グループ、パーソナルカラー、ユーザープリセット、表情差分アイコン、立ち絵、素材クレジット）
- アイコン切り抜きツール内蔵（画像選択時にドラッグ/ズームで切り抜き）
- フキダシテーマ（クラシック / ポップ / シネマ / チャット）とシンプルモード
- ビュー機能（チャット風の閲覧・推敲ビュー、キャラクター単位の台詞通し確認）
- 立ち絵ステージ（編集中ブロックの話者の立ち絵を表情連動で大きく表示）
- ストーリーパネル（画像＋見出しでストーリーを視覚的に管理）
- プロジェクトエクスプローラー（フォルダによるプロジェクト整理）
- エクスポート/インポート
  - 話者・セリフのCSV/TXT、セリフのみ、クリップボードコピー
  - プリセット名＋区切り文字出力（VOICEROID・A.I.VOICEのテキスト読み込み向け）
  - プリセット名の第3列出力（CeVIO AI等向け）
  - グループごと・シーンごとの分割出力
  - プロジェクトJSON・キャラクター設定CSVのバックアップ
  - 動画概要欄用のクレジット出力（合成音声・立ち絵素材）
- データ同期（E2EE暗号化、Proof-of-Workによる濫用対策付き）
- ダークモード対応
- デスクトップアプリケーション対応（Electron）

## 技術スタック
- Next.js / React

- Electron
- Cloudflare Workers（データ同期バックエンド）

### Webアプリケーション版の開発デバッグ
1. `npm run dev` で開発サーバーを起動
2. ブラウザで `http://localhost:3000` にアクセス

### デスクトップアプリケーション版の開発デバッグ
1. `npm run electron-dev` でElectronアプリを起動
2. または `npm run electron-build` でビルドして実行ファイルを作成

## ビルドとデプロイ
1. `npm run build` でビルド
2. `npm run electron-pack` で実行ファイルを作成
