# VoiScripter UI ガイドライン（ポップ／モダン刷新版）

このドキュメントは `VoiScripter Pop UI.dc.html` のモック（1a〜6a）で確定した見た目のルールを、実装に落とせる形で整理したものです。Claude Code などに渡す場合はこのファイルをそのまま参照させてください。

- 対象リポジトリ: `bluemistel/VoiScripter`（branch: `main`）
- 基準モック: `VoiScripter Pop UI.dc.html` の `2a`（台本エディタ）/ `3a`（シンプルモード）/ `3b`（モバイル）/ `4a` `4b`（シネマ・チャット）/ `5b`〜`5e`（ダイアログ）/ `6a`（エクスポート）
- Tailwind のトークン構成、Heroicons、既存の操作フロー、フキダシ4テーマは維持する

---

## 1. 基本方針

1. **枠線をやめて、面と影で階層を作る。** 現行の `border-gray-400` が全要素に出ている状態が「機械的」の主因。区切りは `background` の差、`box-shadow` のヘアライン、余白で表現する。
2. **パーソナルカラーはテキストエリアに集約する。** ブロック外周・アイコンの輪郭には使わない。使ってよいのは「テキストエリアの枠線」「話者名バッジ」「テキストエリアの薄い背景」の3か所。
3. **常時表示するUIを減らす。** 複製・削除だけをホバー表示にし、話者セレクトはアイコン自体に統合する。移動・その他の操作はツールバーとショートカットに残す。
4. **アクセントは1画面に1つ。** primary の塗りは主行動のボタンとアクティブなタブだけ。

`characterColor` をそのまま使い、以下の3か所にだけ適用する。

- テキストエリアの `border: 2px solid {color}`
- テキストエリアの背景 `{color}14`（ライト）/ `{color}24`（ダーク）
- 話者名バッジの塗り。文字色はキャラ色から算出した暗いトーン（ライト・ダーク共通で濃色文字）

適用しない場所: ブロックの外周、アイコンの輪郭リング、ブロックの背景。

## 5. ボタン

3種のみ。これ以外の色を増やさない。

| 種別 | 見た目 | 使いどころ |
| --- | --- | --- |
| プライマリ | primary 塗り＋`on-primary` 文字＋落ち影 | 画面に1つだけの主行動（エクスポート、追加、ブロック追加） |
| セカンダリ | フィールド面の塗り＋`inset 0 0 0 1px {button-border}` の薄い枠、または パネル面＋`inset 0 0 0 1.5px {button-border}` | 同格に並ぶ操作（変更、閉じる、前へ／次へ）。ウェルやカードの面に埋もれないよう、必ず薄い枠を付ける |
| destructive | 強: destructive 塗り／弱: `{destructive}/.10` 塗り＋`inset 0 0 0 1.5px {destructive}/.4`＋destructive 文字 | 削除、データが巻き戻る操作。弱の形には `exclamation-triangle` を添える |

**同価値の操作に強弱をつけない。** 「前へ／次へ」のように対になる操作は必ず同じスタイルにする。

ボタンの見た目は `src/app/globals.css` の `.ui-btn` / `.ui-btn-primary` / `.ui-btn-secondary` / `.ui-btn-secondary-outline` / `.ui-btn-destructive` / `.ui-btn-destructive-weak`（小さいサイズは `.ui-btn-sm`）を既定スタイルとする。コンポーネントでは `Button` / `buttonClass()`（`src/components/common/Button.tsx`）経由で使い、個別に色を書かない。

アイコンボタンは 30〜36px の正方形（モバイルは44px）、角丸は丸または 10px 前後。ホバーで背景にフィールド面が乗る。

## 6. フォームコントロール

- **チェックボックス**: 19px、角丸6px。オフは フィールド面＋`inset 0 0 0 1.5px {hairline}`、オンは primary 塗り＋`check` アイコン、部分選択は primary 塗り＋横バー。
- **ラジオ**: 19px の円。オンは primary 塗り＋中心の小円。
- **トグル**: 38×22px。
- **入力欄・セレクト**: 枠線なし、フィールド面の塗り。フォーカス時のみ `0 0 0 2px {primary}`。セレクトの矢印は `chevron-down` 14px。
- **選択肢のカード化**: ラジオ・チェックの選択肢を面で示す場合、選択中は `primary-tint` の塗り＋`inset 0 0 0 1.5px {primary}`、非選択はウェル面。

## 7. タブ

**アプリ内すべてのタブをシーンタブの形状に統一する。**

- 形: 上角のみ 12px の角丸
- アクティブ: 背景＝その下のコンテンツ面と同色 ＋ `box-shadow: inset 0 3px 0 {primary}`、13px / 700
- 非アクティブ: 背景なし、副次テキスト色、13px / 400
- タブ行の背景はコンテンツより一段暗い帯（ライト `rgba(17,24,39,.035)` / ダーク `rgba(0,0,0,.18)`）

対象: メイン画面のシーンタブ、設定ダイアログのタブ列、エクスポートダイアログのタブ、台本ビューのタブ。

## 8. 台本ブロック（エディタ本体）

### 通常モード

```
[ アバター 60px ] [ テキストエリア（キャラ色2px枠） ]        [ ホバー時: 複製 / 削除 ]
                   ↑ 上辺に話者名バッジを被せる
```

- ブロック: `padding: 12px`、角丸20px、`gap: 12px`、ブロック間 `gap: 10px`
- 話者名バッジはテキストエリアの上辺に `top: -8px; left: 14px` で重ね、`box-shadow: 0 0 0 2px {ブロック面}` で背景から抜く。名前行を独立させないことでブロック高さを 106px → 68px に圧縮している
- プリセット／感情のチップは名前バッジの右隣。背景はパネル面、`border: 1.5px solid {キャラ色}`（グレー面に埋もれさせない）
- テキストエリア: `padding: 16px 16px 14px`、角丸16px、キャラ色2px枠＋薄い塗り
- アバターは縁取り（リング）を付けない。モバイルは 56px
- プリセット／感情のチップは、既定値（標準の表情・プリセット未選択）のときはホバー中か選択中だけ表示する
- ト書きブロック: アバターなし。フィールド面の塗り＋角丸18px＋先頭に `users` アイコン（押すと話者を切り替えるピッカーを開く。キャラクター管理・話者ピッカーの見出しと同じアイコン）。本文は前景色のイタリック（薄いグレーにしない。台本の内容なので読める濃度を保つ）
- プリセットを持つキャラクターのブロックを追加するときは、一番上のプリセットを既定で付ける（引き継いだ表情に連動するプリセットがあればそちらを優先）

### 話者切り替え

- アバター右下に 21px の丸ボタン（`chevron-up-down`）を重ねる。複数ブロックを選択しているときは出さない
- **選択中のブロックにのみ表示する。** 「タップで切替」などのガイドテキストは置かない

### ブロック操作

- 常時表示するアイコンは無し
- ホバー時にブロック右上へ「複製 / 削除」の2つだけをパレットで表示（角丸11px、パネル面、落ち影）
- 上下移動・その他はドラッグ、ショートカット、下段ツールバーに任せる

### シンプルモード（`3a`）

- 1行1ブロック。アバター32px、影とフキダシは無し
- **話者名は表示しない**（アイコンで識別できるため）
- パーソナルカラーはテキスト左の `border-left: 2px solid {キャラ色}` のみ
- 選択行だけ `0 0 0 1px {primary}/.35` の細リング

### モバイル（`3b` / 390px）

- 話者セレクトと移動アイコン列は出さない。アバタータップでボトムシートのキャラピッカー
- ツールバーは 44px のタップ領域を維持し、`gap: 0` / `padding: 4px` で幅に収める（8ボタンで360px）

## 9. フキダシテーマ（4種）

| テーマ | テキストエリア | 話者名 | ト書き |
| --- | --- | --- | --- |
| ポップ（基準） | キャラ色2px枠＋薄い塗り（ライト 8% / ダーク 14%）、角丸18px 均一 | 上辺に被せたバッジ | フィールド面のプレート |
| シネマ | 枠なし。`border-left: 3px solid {キャラ色}` | 字間 `.22em` の小さいラベル、キャラ色の暗いトーン | 中央寄せのイタリック（幕間扱い） |
| チャット | キャラ色1.5px枠＋薄い塗り。アバター側の角のみ6px | 上辺に被せたバッジ。連続発言では省略 | 中央のピル |

チャットは `chatSide` による左右振り分けを維持し、連続発言ではアバターと名前を省略する。選択中の行はブロック面で示し、話者名バッジのリングもその面の色に合わせる。

旧「クラシック」は差がほぼ無かったため「ポップ」に統合した（保存値 `classic` は `pop` として読み込む）。

## 10. ツールバー（下段フローティング）

左から順に、区切り線でグループを分ける。

1. 最上段へ / 最下段へ … `chevron-up` / `chevron-down`
2. 元に戻す / やり直す … `arrow-uturn-left` / `arrow-uturn-right`
3. 上へ / 下へ / 複製 / 削除 … `arrow-up` / `arrow-down` / `document-duplicate` / `trash`（削除のみ destructive）
4. ト書き追加 … 丸ボタンに全角の「ト」（フィールド面より一段濃い塗り＋`inset 0 0 0 1px {hairline}`。CharacterPicker のト書きアバターと表記を揃える）
5. ブロック追加 … プライマリボタン（1つだけ。選択中ブロックの直下に追加し、未選択なら最下段。最下段への追加は Ctrl+B）

`chevron` と `arrow` で「端まで移動」と「1つ移動」を描き分ける。二重シェブロンは印象が強すぎるため使わない。

## 11. ダイアログ

- オーバーレイ: 黒40%
- パネル: 角丸22px、枠線なし、落ち影のみ
- ヘッダー: 左に `primary-text` 色のアイコン＋16px/700 のタイトル、右に丸い閉じるボタン（フィールド面＋`x-mark`）
- 幅の目安: 448px（エクスポート旧版・グループ設定）/ 672px（検索・台本ビュー・設定）/ 960px（エクスポート2カラム）
- ドラッグできるダイアログは左上にドットのグリップを置く（検索）
- 「変更が即時保存される」画面のフッターは「閉じる」のみ。保存ボタンを置かない

### エクスポート（`6a`）

デスクトップ前提の2カラム。

- **左（必須・384px 固定）**: ステップ番号つきで 1 出力する内容（ラジオ3択）→ 2 ファイル形式（`.csv` / `.txt` の2枚カード。セレクトは使わない）。下端に出力プレビュー（モノスペース）とエクスポートボタンを固定
- **右（任意）**: 「出力範囲を絞り込む」。4つの選択肢をカードに分け、チェックしたものだけ詳細エリアが開く
  - グループごと → グループ選択＋各グループの対象キャラ名チップ
  - 特定のシーンのみ → シーン選択
  - 選択中のブロックのみ → 対象ブロック数
  - プリセット名と区切り文字 → 1文字入力＋候補チップ＋その設定での出力例
- デフォルトは「話者とセリフの両方 / .csv / 絞り込みなし」。右カラムを見なくても合成音声ソフト向けの形式で出力される
- 「ト書きを含める」「プリセット名を3列目に追加」は ① のラジオの下に、ウェル面で1グループにまとめて置く（ラジオの選択肢と区別するため）

### グループ設定（`5d`）

- 1グループ＝1カード。上段にグリップ・グループ名・削除ボタン、下段にクレジット表記の入力欄
- グループ名の編集ボタン（`pencil-square`）は**ホバー時のみ**名前の右に表示
- クレジット表記の説明はツールチップだけにし、ダイアログ下部には出さない

### 設定（`5e`）

- タブは §7 の形状
- 構成は実装通り: データ保存先 → 動作モードの切り替え → 表示（フォント ＞ 表示フォント・フォントサイズ、シンプルモード、フキダシのデザイン、立ち絵ステージ＋表示サイド）
- 「ブラウザ内データベースに戻す」は destructive の弱スタイル

## 12. アイコン

Heroicons 24 outline のみ。サイズは 14 / 16 / 19 / 22px。

| 用途 | アイコン |
| --- | --- |
| 端まで移動 | `chevron-up` / `chevron-down` |
| 1つ移動 | `arrow-up` / `arrow-down` |
| 元に戻す・やり直す | `arrow-uturn-left` / `arrow-uturn-right` |
| 複製 | `document-duplicate` |
| 削除 | `trash` |
| 話者切り替え | `chevron-up-down` |

## 13. モーション

- ホバー表示の出現: `opacity .16s ease`
- 位置は動かさない（ホバーでレイアウトが変わるとブロックがずれるため、パレットは `position: absolute` で重ねる）

---

## 14. 禁止事項

- 全要素への `border` 適用（`border-gray-400` の常時表示）
- パーソナルカラーをブロック外周・アイコン輪郭に使うこと
- 黄色／琥珀系の警告色を新設すること
- 同価値のボタンに強弱をつけること
- 三角のしっぽを持たないテーマでテキストエリアの角を尖らせること
- シンプルモードで話者名を表示すること
- ブロック操作アイコンを常時表示すること
